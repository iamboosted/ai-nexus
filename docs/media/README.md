# README visuals

These assets were prepared on 2026-10-15 for the AI Nexus source-only preview.

- `ai-nexus-banner.svg` is original vector artwork, using the existing AI Nexus
  chevron mark and orange/charcoal palette. It contains no scripts, external
  resources, embedded files or font binaries.
- `dashboard.png`, `settings-models.png`, `settings-appearance.png` and
  `compact-hud.png` are captures of the project's actual browser UI.
- `appearance-motion.gif` records the actual Appearance controls changing from
  orange to teal to violet and back to orange. It loops for presentation.

The captures show Qwen 3.8 27B, GPT-OSS-20B and MiniCPM-V 4.7, using display names
from the launcher roster with illustrative configuration and generic example paths.
These entries are not model recommendations or evidence of runtime compatibility.
No actual model files, inference server, optional service or monitoring helper
was used. The browser preview has no native IPC; runtime controls and persistence
are unavailable. CPU/RAM/GPU readings remain unavailable. The native desktop app
has additional behavior described in the main README and validation record.

All launcher frontend source files used for the existing compiled preview were
compared byte-for-byte with the public source before capture. Installed Chrome
and Pillow were used without installing or downloading tools. Browser profiles,
capture scripts, fixture configuration, intermediate frames and review output
are development artifacts outside the publication file set.

The PNG files are freshly encoded from captures with descriptive metadata
removed. The GIF contains frame timing and loop information, with no comments
or private metadata. No desktop, browser account, local user name or real model
collection appears in the images. System fonts were rendered locally; no fonts
are distributed.

Original artwork and captures are covered by the project's MIT license.
The underlying third-party React libraries keep their existing notices and terms.
These visuals demonstrate the interface; they are not evidence of inference or
GPU compatibility, a native UI acceptance test or a clean-Windows installation.
